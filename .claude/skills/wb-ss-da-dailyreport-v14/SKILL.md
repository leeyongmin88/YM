# wb-ss-da-dailyreport-v14

GA↔매체 광고데이터를 날짜+매칭키로 1:1 결합해 통합 생성, 미맵핑 분류, 광고비 보정, 각종 리포트 + 브랜드 Total 대시보드 · 일별 광고비집행 매트릭스 · 전체 일별 성과 표 · 동적 자동 플랫표까지 '최종 리포트 형태' 전체를 만든다. v13 후속(주간현황·월요일주차·표순서·주말색·월말일행·RTB보정 추가). F 사본 재동결은 wb-ss-da-report-f-refresh(-v2), 코멘트는 wb-ss-daily-ad-report-comment 별도 스킬(이 스킬에서 제외).

## When to use

"새 데이터 반영/최종 리포트까지/Total 대시보드/집행현황/전체 일별 성과/미맵핑/N검색/Naver SA/플랫표 자동화/주간현황/주말색/주차" 류. (v13을 대체하는 최신본)

순서: ①통합 재빌드 → ②미맵핑 → ③매체별 리포트(주간현황·요일별·일자별+월요일주차+주말색) → ④전체일별 표 → ⑤Total 대시보드 → ⑥리포트 추가 요청 → ⑦●광고비집행현황 → ⑧플랫표(동적 자동). (이후 F사본·코멘트는 별도 스킬)

## 공통 원칙 (매우 중요)

- 모든 집계는 통합 SUMIFS로. 리포트 간 셀참조(예 `='MI_K디스'!D7`)는 시트 재구성 시 `#REF!`로 깨지므로 금지 — 통합 기준 SUMIFS(매체/브랜드/캠페인패턴/날짜)로 뽑는다.
- SUMIFS 범위는 통합 전체 커버(예 `통합!$X$2:$X$5833`). 좁은 고정범위 금지(뒤쪽 매체 행 누락 → 전 일자 0).
- 레이아웃: 모든 리포트·대시보드는 A열·1행 비우고 B2부터. 긴 텍스트 셀은 좌측 정렬(A열 침범 금지).
- 통합 컬럼: A날짜(serial) B날짜키(YYYYMMDD) C매체 D브랜드 E캠페인 F광고그룹 G소재 H광고비 I노출 J클릭 K구매 L매출 M세션 N매핑상태 O매칭키 P회원 Q회원세션.
- 매체×캠페인패턴(통합!$E 와일드카드): 브랜드검색=NaverSA&"bsa", 키워드/파워링크=NaverSA&"cpc", 쇼핑검색=NaverSA&"shopping", 엠버서더=NaverSA&"Ambassador", 플레이스=NaverSA&"place", 스마트채널=Naver&"smart", 애드부스트=Naver&"advoost", 구글키워드SA=Google&"_cpc", 구글PMAX=Google&"pmax", GDN=Google&"gdn", 유튜브=Google&"youtube", 카카오네이티브=KKO&"ntv", 비즈보드=KKO&"biz", 카탈로그=KKO&"_ca", 크리테오=Criteo, RTB=RTB, 인스타성과형=Meta&"pf", 인스타노출형=Meta&"br". 지표열: 노출←I 클릭←J 광고비←H 전환←K 매출←L 회원←P 세션←M.

## ① 통합 빌드 / ② 미맵핑

- v11/v12 그대로. 통합은 완전 동적 자립형(정액 6계열×월일수 IF 블록 + VSTACK/MAP 스필: 소스순 Meta_IT,MI,EBM,Google,KKO,Criteo,RTB,Naver_Smart,Naver_Advoost,Naver_SA). 광고비계수(Meta·Google·Criteo=/0.9*1.1, RTB·KKO=*1.1, Naver 계열 그대로), GA키 도출(추가정보 동적로드), K/L/M·P/Q=MAP+SUMIFS GA조인. 소스 갱신 시 자동 반영·자동 축소.
- 소스 텍스트-숫자 함정(RTB 등): 소스 노출·비용이 공백구분 텍스트("43 893")면 통합 계수곱에서 `#VALUE!`. 소스 헬퍼열을 `=IF(원본="","",VALUE(SUBSTITUTE(SUBSTITUTE(원본,CHAR(160),"")," ","")))`로 숫자화하고, 통합 스필이 원본(텍스트)열이 아니라 헬퍼열(_num)을 참조하게 앵커 수정.
- 월 롤오버/지난달 잔존 점검: 매체별 통합 날짜 분포를 매체×날짜키로 전수 확인. 한 매체만 지난달(예 Meta_IT 6월)이면 소스 갱신 누락 → 사용자 확인 후 재반영.

## ③ 매체별 리포트 (통합 SUMIFS) — 표 구성·주차·주말색 규칙

- 단일캠페인(구글SA/피맥스/GDN/유튜브/RTB): 표 순서 = ■주간현황 → ■요일별 평균 → ■일자별 성과(사용자 선호). 재배치는 Range.moveTo로 블록 이동(요일별 AVERAGEIF의 일자별 절대참조가 자동 갱신됨).
- 크리테오·K디스·N디스·N검색: 유형별 누적 + (주간현황) + 전체일별 + per-type 일자별.
- 메타 성과형/브랜딩형: 누적 요약(광고그룹별) + (주간현황) + 전체일별 + 운영중 광고세트만.
- 주간현황 표(없으면 생성) — 누적 요약 표 바로 아래(전체 일별 위): 헤더 ■ 주간현황, colhdr B주차 C기간 D노출수 E클릭수 F클릭률 G클릭당비용 H광고비 I전환수 J매출 K회원가입 L세션수 M전환율 N전환당비용 O회원가입율 P ROAS Q객단가, 5주차 행. 서식은 누적요약의 ■/colhdr/데이터행에서 copyFrom. 삽입은 dailyHeader 위치에 8행(■+colhdr+5주+공백). 지표=통합 SUMIFS(매체+브랜드+[캠페인패턴 pf/br 등]+주차 날짜범위), 비율=IFERROR. 합계열 소스 D←통합I,E←J,H←H,I←K,J←L,K←P,L←M. 검증: 주간 5주 합 = 누적 TOTAL(=전체일별 합계).
- 주차 규칙 = 월요일 기준(매우 중요). 7일블록(`INT((DAY-1)/7)+1`) 금지 — 7/6(월)이 1주차로 오탐.
  - 값 방식(Total 일자별 A열): `=WEEKNUM($C,2)-WEEKNUM(DATE(YEAR($C),MONTH($C),1),2)+1`.
  - 날짜범위 방식(주간현황·개별 리포트 ■주간현황): 라벨·SUMIFS 경계를 월요일 블록으로. 예 7월: 1주 07/01~07/05, 2주 07/06~07/12, 3주 07/13~07/19, 4주 07/20~07/26, 5주 07/27~07/31(월 첫날 요일 따라 1주는 부분). 개별 리포트가 하드코딩 7일블록이면 날짜리터럴(`>=YYYYMMDD,<=YYYYMMDD`)+라벨을 일괄 치환.
- 주말 색상 — 일자별 표 요일·날짜 셀: 토요일 파란색 `#0000FF`, 일요일 빨간색 `#FF0000`. 조건부서식 API는 이 클라이언트에서 ConditionalRangeFont.color가 InvalidSelection으로 거부됨 → 직접 폰트색으로 지정. 탐지: 요일열(한글 1자 월~일) 바로 오른쪽이 date-serial(45000~48000)인 행 → 그 두 셀에 색. N검색은 상품유형별 일자별표가 가로 다중블록(80~97열) → 전 열 스캔(요일/날짜가 B/C 또는 C/D 등 시트마다 다름). 직접색이라 월 롤오버 시 재적용 필요.

## ④ 전체 일별 성과 (브랜드 전체) 표 — 메타·K디스·크리테오·N디스

"브랜드 전체(모든 캠페인유형 합산) 일별"(1일~월말). 지표=SUMIFS(통합!col, 매체, 브랜드, 날짜키). 메타는 캠페인 pf/br 추가, N디스 매체="Naver". 16컬럼, 합계=SUM, 비율=IFERROR. 범위는 통합 전체($5833). 배치: 누적요약 →(공백)→ (주간현황) →(공백)→ ■전체 일별 → per-type 블록.

## ⑤ 브랜드 Total 대시보드 (MI_Total·IT_Total·EBM_Total)

- [매체 예산 집행율]/[매체 총 누적](통합 SUMIFS, 셀참조 금지, EBM은 플레이스 행 포함)/[디바이스별]/[일자별 성과]/[요일별 평균]/[주간].
- [일자별 성과]: 1일~월말일(예 7/31)까지 전 일 행 포함(빠졌으면 합계행 앞에 행 추가 후 지표 SUMIFS 채우고 합계 SUM 범위·주간 SUMIF 범위를 새 행까지 확장). A열=월요일기준 주차수식(위 ③). 브랜드 전체(매체 차감 금지). 매체총누적합계=일자별합계=브랜드 통합합계 3중 검증.
- [주간]=SUMIF(일자별 A주차, 주차번호) — A열 주차수식만 월요일기준으로 고치면 자동 교정. 라벨 "N월 M주".
- [요일별 평균]=AVERAGEIF. 디자인: 나눔고딕, 그룹헤더 `#002060` 흰, colheader `#D9E2F3`, 요일셀 `#DEEAF6`(일 `#C00000`), 음영 `#E7E6E6`/`#D8D8D8`.

## ⑥ 리포트 추가 요청 (일별 광고비 집행 매트릭스)

행3 헤더 브랜드·매체·날짜열(serial)·월누계. 셀=SUMIFS(통합!$H, 매체, [브랜드,] 캠페인패턴, 날짜). 미집행 매체 행 삭제, 빠진 매체(애드부스트 등) 추가.

## ⑦ ●광고비집행현황 (다브랜드 일별 매트릭스)

시선전체+브랜드별, 전체/SA소계/DA소계, 날짜 세로, 누적=SUM. 셀=SUMIFS(통합!$H, 매체, [브랜드,] 날짜). N검색=NaverSA전체(플레이스 포함), G검색=Google&_cpc, G디스=Google총−cpc, N디스=Naver, K디스=KKO, 크리테오=Criteo, RTB=RTB, I디스=Meta.

## ⑧ 플랫표 (통합_캠페인일자별) — 동적 자동 권장

- (A) 동적 자동(권장) 통합_캠페인일자별_자동: FILTER/UNIQUE/SUMIFS 스필. 검색광고 제외(NaverSA 전체 + Google&_cpc) + 실제집행(광고비·노출·클릭>0) UNIQUE, 지면/유형/구분/주차 규칙 자동산출, WEEKNUM은 MAP(LAMBDA). 전체 수식·서식은 wb-ss-da-flat-auto-dynamic 참조.
- (B) 수동 나열(통합_캠페인일자별_신규): 날짜×브랜드×광고그룹(F) 행, 지표=통합 SUMIFS(키 date C+brand D+광고그룹 F, 범위$5833), B주차=WEEKNUM(C,2), F구분=카테고라이징 COUNTIF, 행3=SUBTOTAL 합계. 매일 신규 날짜블록·신규 캠페인 추가 + 소스 캠페인명 드리프트 점검 필수(예 …_0701-0705→…_(0701-0705)(0706-0712); 옛 이름 SUMIFS=0). 완성/재정합 방법: 자동 표의 비검색 UNIQUE 조합(날짜→브랜드 정렬, 유형·지면 규칙산출)을 추출해 수동표 C/D/E/G/H(값)만 재기입 + 나머지 열 수식 유지, SUBTOTAL 범위 확장. 검증=수동 합계(노출·집행·수익·거래)=자동 표=통합 비검색 일치.

## 실행 함정

- 대량수식: calculationMode=manual→calculate(Full), execute_office_js 쓰기 후 await sync. formulas 배열 폭 정확히.
- SUMIFS 끝행이 통합보다 짧으면 조용히 0/과소 → 넉넉한 범위($5833).
- 행 삽입/이동: 통합 SUMIFS면 안전. moveTo는 외부 참조(요일별→일자별) 자동 갱신·내부 상대참조 보존. 삽입행은 위 행 서식 상속.
- 조건부서식 폰트색이 InvalidSelection이면 직접 폰트색으로 대체.
- 동적배열: WEEKNUM 등 배열인자 `#VALUE!` → MAP(LAMBDA). 스필영역 개별셀 편집불가.
- 병합셀: 전범위 재기입은 앵커만 적용(대개 무해). 날짜 $A=serial, $B=YYYYMMDD.

## 검증(Done when)

`#REF!`/`#VALUE!` 0, 통합=GA매핑됨 일치·지난달잔존 없음, 각 리포트 일자별합=누적=통합 재집계, 주간현황 5주합=누적 TOTAL, Total 매체총누적합=일자별합=브랜드 통합합·주간블록>0·월말일 행 포함, 집행현황 시선전체=브랜드합, 플랫(자동)=수동=통합 비검색, 주차는 월요일기준(7/6=2주차), 주말 색(토 파랑·일 빨강) 일자별표 전 블록 적용, 운영중/미집행 매체 점검. 쓰기 후 재읽기(값·표시텍스트·서식), 큰 표 이미지 점검.

## 월 롤오버

누적요약 날짜무관 SUMIFS라 두 달 섞이면 오류→월별 파일 복제. 절차: 추가정보 신규월 갱신→소스 교체→통합 재빌드→SUMIFS 리포트 자동반영→메타(운영중만)·Total(월말일 행)·집행현황 재생성/검증→플랫 자동시트 자동·수동표 재정합→주차 월요일기준 재확인·주말 직접색 재적용→누락 점검. (F사본·코멘트는 별도 스킬)
